# Public paper to tool map

This file follows the public record through *The Secondary Term in
Digit-Collision Energy*. If you arrive from one of those papers, it points to
the `nfield` command to run.

The command names follow the mathematics, not the publication order. One
command can serve several papers, and one paper can need several commands.

- `ready`: command, help, verifier, CLI test, and daemon test are present.
- `partial`: some of the calculation is present, but the path is unfinished.
- `not integrated`: the work has not been brought into the public tool.

`ready` is a software status. A finite run is still a finite run. Numerical
checks, exact identities, and universal proofs remain different things.
